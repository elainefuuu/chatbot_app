# chatbot_app

Problem Statement: Pharmacists or clinic need a better understanding of patient opinions on medications to improve satisfaction with treatment, but the abundance of reviews and drug information makes it difficult to discern what changes are necessary. 

Target user : Pharmacy Department 

Objective: 
1) To classify patients condition like Depression, High Blood Pressure, and Type 2 Diabetes, based on patient's feedback on drug effectiveness. 
2) Identify the side effect of drugs based on patient reviews and their ratings. 
3) Provide suggestion on how to improve the patient care (e.g. more suitable drug, etc).
